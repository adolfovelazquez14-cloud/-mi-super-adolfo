MI SÚPER - PAQUETE WEB

Este paquete contiene una aplicación web instalable (PWA).

Archivos:
- index.html: aplicación
- manifest.json: configuración de instalación
- sw.js: funcionamiento offline

IMPORTANTE:
Para que el iPhone pueda instalarla como app, los archivos deben publicarse en una dirección HTTPS.
Después, en Safari:
1. Abre la dirección de la aplicación.
2. Pulsa Compartir.
3. Elige "Añadir a pantalla de inicio".
4. Abre "Mi Súper" desde el icono.

La aplicación guarda las casillas y los productos agregados en el dispositivo mediante almacenamiento local.
